# Music Playlist Management System

## Objective
To develop a simple music playlist management system using a Singly Linked List.

## Problem Statement
The project is designed to manage songs in a playlist. It allows users to add, delete, search, and display songs easily.

## About the Project
This is a Python-based music playlist management system that uses a Singly Linked List to store and manage songs.

## Features
- Add Song
- Delete Song
- Search Song
- Display Playlist

## Technology Used
- Python
- Singly Linked List

## How It Works
The user can select an operation from the menu and manage songs in the playlist.

## Conclusion
This project helps in understanding the practical use of Singly Linked List and basic Python programming concepts.
